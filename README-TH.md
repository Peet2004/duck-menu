# เว็บสั่งอาหาร — เป็ดย่างบางกะปิ

ลูกค้าสแกน QR → เลือกเมนู (ธรรมดา/พิเศษ + ของเพิ่ม) → กดสั่ง → ออเดอร์ส่งไปที่แม่ค้า  
แม่ค้าเปิดหน้าแยก (`seller.html`) ใส่รหัสเพื่อดูออเดอร์ทั้งหมดและยอดขายของแต่ละวัน

ข้อมูลเมนู/ราคา/ของเพิ่ม แก้ใน **Google Sheet** · ออเดอร์เก็บในแท็บ `Orders` ของชีตเดียวกัน (ผ่าน Google Apps Script)

## โครงสร้างไฟล์

```
index.html            หน้าลูกค้า (เมนู + สั่งอาหาร)
seller.html           หน้าแม่ค้า (ใส่รหัส → ออเดอร์ + ยอดขาย)
css/
  base.css              สี ฟอนต์ แถบหัว ปุ่มทั่วไป animation (ใช้ร่วม)
  customer-menu.css     แถบหมวดหมู่ + การ์ดเมนู
  customer-detail.css   popup เลือกธรรมดา/พิเศษ/ของเพิ่ม
  customer-cart.css     ปุ่มออเดอร์ลอย + หน้าต่างออเดอร์ + หน้าเสร็จสิ้น
  seller.css            หน้าแม่ค้า

  shared/               ใช้ร่วมสองฝั่ง
    config.js             ★ ตั้งค่าลิงก์ทั้งหมดที่นี่
    menu-source.js        โหลดเมนู/Addons จาก Google Sheet
    orders-api.js         ส่ง/ดึงออเดอร์ (Apps Script, หรือจำลองใน ?demo)
    pricing.js            คิดราคา      categories.js  หมวดหมู่
    csv.js / utils.js / icons.js / artwork.js / demo-data.js
  customer/             ฝั่งลูกค้า
    main.js               จุดเริ่มต้น
    menu-store.js         ข้อมูลเมนู      menu-page.js    หน้าเมนู
    item-detail.js        popup เลือกตัวเลือก + ปุ่ม "เพิ่มอาหาร"
    cart-store.js         ออเดอร์ที่เลือกไว้
    cart-button.js        ปุ่มออเดอร์กลมซ้ายล่าง
```

## ลองก่อนโดยไม่ต้องตั้งค่า
- ลูกค้า: `index.html?demo`
- แม่ค้า: `seller.html?demo` รหัส `1234`  
(ใช้เมนูสมมติ ออเดอร์เก็บในเบราว์เซอร์เครื่องนั้น ลูกค้ากับแม่ค้าต้องเปิดในเบราว์เซอร์เดียวกันถึงจะเห็นออเดอร์ตรงกัน)

## ตั้งค่า Google Sheet

### แท็บ `Menu` (ของเดิม + คอลัมน์ใหม่)
`id | name | category | description | price | special_extra | image | available | featured | addons`

- `price` = ราคาธรรมดา
- `special_extra` = **ราคาที่บวกเพิ่มเมื่อเลือกพิเศษ** เช่น `10` หรือ `20` (ว่าง/0 = เมนูนี้ไม่มีแบบพิเศษ) หน้าเว็บจะโชว์ทั้งราคาธรรมดาและพิเศษ
- `addons` = ว่าง: เพิ่มของได้เฉพาะหมวด **ข้าว** และ **บะหมี่** · `FALSE`: ปิดของเพิ่มเฉพาะเมนูนี้ · `TRUE`: เปิดให้เมนูนอกหมวดนั้น
- หมวด **เป็ดย่าง**: ใส่ `category` = `เป็ดย่าง` แล้วเพิ่มได้เรื่อย ๆ (จานเล็ก / จานใหญ่ / ครึ่งตัว / 1 ตัว ดูตัวอย่างใน `sheet-templates/Menu.csv`)
- **ควรกรอก `id` ให้ไม่ซ้ำทุกแถว**

### แท็บ `Addons` (ใหม่)
`name | price | available | for`  
`for` = ว่าง (ใช้ได้ทั้งข้าวและบะหมี่) หรือ `ข้าว` / `บะหมี่` เพิ่ม/ลบ/ปรับราคาที่นี่ได้เลย

### เผยแพร่เป็น CSV
ไฟล์ > แชร์ > เผยแพร่ไปยังเว็บ → เลือกแท็บ `Addons` รูปแบบ CSV → คัดลอกลิงก์ไปใส่ `ADDONS_CSV_URL` ใน `js/shared/config.js`  
(แท็บ `Menu` ใช้ลิงก์เดิม) **ห้ามเผยแพร่แท็บ `Orders`**

## ตั้งค่าระบบรับออเดอร์ (Google Apps Script)
1. เปิด Google Sheet เดียวกับเมนู → ส่วนขยาย → **Apps Script**
2. วางโค้ดจาก `backend/Code.gs` ทับไฟล์เดิม · (ตั้งค่าโปรเจ็กต์ → ติ๊ก "Show appsscript.json" แล้ววางค่าจาก `backend/appsscript.json` เพื่อใช้เวลาไทย)
3. ตั้งค่าโปรเจ็กต์ (รูปเฟือง) → **Script properties** → เพิ่ม `SELLER_PIN` = รหัสของแม่ค้า (แนะนำ 6 หลักขึ้นไป)
4. เลือกฟังก์ชัน `setup` → กดเรียกใช้ → อนุญาตสิทธิ์ (สร้างแท็บ `Orders`)
5. Deploy → New deployment → ประเภท **Web app** · Execute as: **Me** · Who has access: **Anyone** → คัดลอกลิงก์ที่ลงท้าย `/exec`
6. วางลิงก์ใน `ORDER_API_URL` ใน `js/shared/config.js` แล้วอัปโหลดขึ้น GitHub Pages
7. ทุกครั้งที่แก้ `Code.gs` ต้อง Deploy → Manage deployments → แก้เป็น **New version**

## วิธีใช้งานจริง
- **ลูกค้า**: สแกน QR → เปิด `index.html` → กดเมนู → เลือกธรรมดา/พิเศษ/ของเพิ่ม/จำนวน → **เพิ่มอาหาร** → ปุ่มกลมซ้ายล่างโผล่ → กดเข้าไปตรวจรายการ → ใส่ชื่อและจำนวนคนบนโต๊ะ (บังคับ) → แถบ **สั่งอาหาร** → หน้าเสร็จสิ้นแสดงเลขออเดอร์ → กลับหน้าเมนู
- **แม่ค้า**: เปิด `seller.html` (เก็บลิงก์นี้ไว้เอง อย่าทำ QR ให้ลูกค้า) → ใส่รหัส → เห็นออเดอร์ใหม่ทุก 10 วินาที, กด **ทำเสร็จแล้ว** / **ยกเลิก**, เลือกวันที่ดูยอดขายย้อนหลัง, กด "เปิดเสียงเตือน" ให้มีเสียงเมื่อมีออเดอร์ใหม่

## ข้อควรรู้
- ราคาจริงคำนวณที่ Apps Script จากชีตเสมอ แก้ราคาจากเบราว์เซอร์ไม่ได้ ถ้าราคาในชีตเปลี่ยนระหว่างที่ลูกค้าเลือก ยอดในหน้าเสร็จสิ้นจะเป็นยอดล่าสุด
- ยอดขายไม่นับออเดอร์ที่ยกเลิก · เลขออเดอร์เริ่ม 001 ใหม่ทุกวัน (เวลาไทย)
- การป้องกัน: รหัสแม่ค้าอยู่ที่ Apps Script ไม่ได้อยู่ในโค้ดเว็บ ใส่ผิด 5 ครั้งจะล็อก 1 นาที แต่ลิงก์ Web App เป็นสาธารณะ จึงควรใช้รหัสที่เดายาก
- เมนูที่ดึงจากชีตมาแสดงอาจช้าได้ถึง 5 นาที หรือรีเฟรชหน้า
